## Future governance boundary

Before any source can be ingested, a separately reviewed V5 revision must select it using only:

- license or terms verification;
- source provenance;
- BTC/USDT Spot 1-hour UTC identity;
- closed candles; and
- absolute continuity.

It must not use signals, returns, accuracy, backtests, PnL or any performance metric to choose a
source or range. A subsequent revision must separately preregister one candidate, its parameters,
costs, folds and gates before it can freeze a validated input.

Strict OOS from 2025 remains sealed. Until every future governance gate is passed, the default is
`NEUTRAL`; no broker, order, live-trading, ML, credential, data-ingestion or OOS activity is
authorized.
